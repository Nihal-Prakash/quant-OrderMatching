An order matching engine built in C++ from the IICPCxAmalthea workshop challenge. It maintains a limit order book with price-time priority, executes incoming orders against the best available quotes, and emits explicit acknowledgments, trades, rejections, cancellations, and expirations. Limit, market, immediate-or-cancel, and fill-or-kill orders are supported, alongside self-trade prevention and book snapshots. Prices use integer ticks to keep comparisons deterministic, while resting quantities and order counts remain visible for inspection. This project placed 6th at the workshop. Thank you to IICPCxAmalthea for organizing the workshop and making market microstructure fun to explore through hands-on engineering and practical systems thinking together.
